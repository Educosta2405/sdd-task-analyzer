# TaskAnalyzer — Bootcamp III

Projeto acadêmico de análise de tarefas com Python 3.11+, especificação SDD reconstruída com base nos enunciados das Fases 1 e 2, governança de IA e testes pytest.

## Organização
- `CONTEXT_RULES.md`: regras de uso da IA
- `specs/task_analyzer_spec.md`: contrato de comportamento
- `src/task_analyzer.py`: implementação
- `tests/test_harness.py`: testes

## Como executar
```bash
python -m pip install -r requirements.txt
python -m pytest -q
```

**Observação:** a Fase 1 não foi entregue; a especificação deste repositório é reconstruída com base nos enunciados, não uma reprodução de uma entrega anterior.
